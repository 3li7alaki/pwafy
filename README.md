# pwafy

> Make an installed web app feel like an app.

A bottom bar under the thumb, pull to refresh, sheets that drag, an install prompt that knows
iOS from Android, and every Safari trap we already fell into once. Shipped as a
[shadcn GitHub registry](https://ui.shadcn.com/docs/registry/github): the code lands in your
app and your app owns it.

```bash
npx shadcn add 3li7alaki/pwafy/<item>
```

## Status

Early. Items are being extracted from apps that already feel right.

## Why

See [`docs/principles.md`](docs/principles.md): what pwafy is for, what it refuses to become,
and the lessons it encodes.
